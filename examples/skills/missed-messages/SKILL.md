# Missed messages

Search every authorized connected chat source for messages that are still
waiting on my attention. Read the conversation around each candidate to check
whether I already replied or someone else resolved it. Unread messages alone
are not evidence that I owe a response.

Prioritize direct questions, mentions, and requests where someone is blocked on
me. Exclude bots, announcements, resolved requests, and questions aimed at
someone else. On the first run, search the past seven days; on later runs, use
the last successful coverage point with a one-day overlap and recheck previously
unresolved items.

Put the result on the space's main canvas. Group follow-ups into blocking
someone, awaiting my reply, and worth a look. Use a checkbox for each item and
include who asked, the age of the request, what they need in one sentence, why
it still needs attention, and a direct thread link. Include a suggested next
step or draft only when the thread provides enough evidence.

Keep stable source/thread references. Read the previous result when provided,
carry forward unfinished items, preserve user-authored drafts, and do not
reintroduce checked-off or dismissed requests unless new messages require a
response. Do not modify previous spaces.

State the actual search window and coverage for each source. If a source is
unavailable, report a partial result or a connection problem, never "nothing
missed." If all searches succeed and nothing needs attention, save an explicit
empty result. Do not send replies, mark messages read, or change anything in
the connected tools.
